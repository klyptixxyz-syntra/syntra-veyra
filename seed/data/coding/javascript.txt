Assistant: Use const, for example: const score = 10;

User: how do I declare a variable in JavaScript
Assistant: Use let when the value will change, for example: let score = 0;

Assistant: For example: const items = ["apple", "banana", "orange"];

Assistant: Use pop, for example: const removed = items.pop();

Assistant: Use for...of for values, for example: for (const item of items) { console.log(item); }
